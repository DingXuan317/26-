# ROS2 话题通信作业 —— 启动说明

> 作业要求：在自己的工作空间里创建 ament_cmake 功能包，用 C++ 写一个发布者和一个订阅者；
> 发布者发消息，订阅者每收到一条就显示原文和对应回复；用一个 launch 文件同时启动两个节点。
> 本说明对应功能包 `chat_demo`。

---

## 一、运行环境

| 项目 | 版本 |
| --- | --- |
| 操作系统 | Ubuntu 22.04.5 LTS |
| ROS2 版本 | Humble Hawksbill（`/opt/ros/humble`） |
| 工作空间 | `~/ros2_ws` |
| 功能包 | `chat_demo`（ament_cmake / C++17） |
| 话题名 | `/chat` |
| 消息类型 | `std_msgs/msg/String` |

---

## 二、目录结构

```
~/ros2_ws/src/chat_demo/
├── CMakeLists.txt              # 编译规则：编哪些程序、装到哪
├── package.xml                 # 功能包清单：包名、依赖
├── launch/
│   └── chat.launch.py          # 启动文件：同时启动两个节点
└── src/
    ├── publisher_node.cpp      # 发布者节点 chat_publisher
    └── subscriber_node.cpp     # 订阅者节点 chat_subscriber
```

---

## 三、启动步骤（3 步）

### 第 1 步：编译

```bash
cd ~/ros2_ws
colcon build --packages-select chat_demo
```

看到 `Summary: 1 package finished` 就是编译成功。

### 第 2 步：让当前终端认识这个功能包

```bash
source install/setup.bash
```

> 必须执行。否则 `ros2 launch` 会报 `Package 'chat_demo' not found`。

### 第 3 步：一条命令同时启动两个节点

```bash
ros2 launch chat_demo chat.launch.py
```

按 `Ctrl+C` 退出。

## 五、可调参数

发布间隔由参数 `interval` 控制（单位：秒，默认 1.0），改 launch 文件或命令行都行：

```bash
# 命令行临时改成 0.5 秒一条（不用重新编译）
ros2 launch chat_demo chat.launch.py --ros-args -p interval:=0.5
```

改 `launch/chat.launch.py` 里的 `parameters=[{'interval': 1.0}]` 是持久修改。

想改问答内容，只改 `src/subscriber_node.cpp` 里的 `replies_` 表，
或 `src/publisher_node.cpp` 里的 `questions_` 数组，然后重新 `colcon build`。

## 六、验证话题确实存在的常用命令

```bash
ros2 node list                 # 看有哪些节点在跑
ros2 topic list                # 看有哪些话题（应有 /chat）
ros2 topic info /chat          # 看话题类型和发布/订阅数量
ros2 topic echo /chat          # 实时打印话题上的消息内容
ros2 interface show std_msgs/msg/String   # 看消息结构（只有一个 string data）
```

## 七、常见问题

| 现象 | 原因 | 解决 |
| --- | --- | --- |
| `Package 'chat_demo' not found` | 没 source 或包不在 `src/` 下 | `source install/setup.bash`，并确认 `~/ros2_ws/src/chat_demo` 存在 |
| `ros2: command not found` | 没 source 系统 ROS | `source /opt/ros/humble/setup.bash` |
| `Executable 'chat_publisher' not found` | 没编译 / 没 install 规则 | 重新 `colcon build`，检查 CMakeLists 里 `install(TARGETS ...)` |
| launch 提示找不到 launch 文件 | CMakeLists 没装 launch 目录 | 检查 `install(DIRECTORY launch ...)` 后重新编译 |
| 订阅者收不到消息 | 话题名不一致 / 没在同一个 `ROS_DOMAIN_ID` | 两边都用 `/chat`；`echo $ROS_DOMAIN_ID` 保持一致 |
| 改完代码没变化 | 忘了重新编译 | `colcon build --packages-select chat_demo` 后再启动 |
| 两个终端互相看不到对方 | 有一个终端没 source | 每个终端都要 `source /opt/ros/humble/setup.bash` + `source install/setup.bash` |
